About the Game

A technical contest testing layout and frontend development skills to design web pages using HTML and CSS.

PLAY FAIR

Gaming Rules

  • Participants must handle both the design (UI/UX, colors, layout) and development (code, links, functionality).
  • The main homepage is compulsory and must be fully completed.
  • The participant who completes a fully working, clean, and user-friendly website first (with all basic sections functional) wins.
  • Only proper web standards, original work, and fair practices are allowed (strictly no plagiarism and no ready-made templates without giving credit).
