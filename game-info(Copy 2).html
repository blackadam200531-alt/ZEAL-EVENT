About the Game

PLAY FAIR

Gaming Rules

  • Each participant/pair receives the same problem statement(s), input/output format, constraints, and time limit.
  • Use only the permitted editor and standard language features. Unless explicitly allowed, do not use the internet, AI assistants, messaging apps, pre-written solutions, or help from others.
  • Submit source code in the required file format and naming convention before the deadline. Late submissions may be rejected.
  • Code must run in the organiser’s test environment. Participants must not hard-code sample answers or alter the test files.
